What does BOTTLENECKED mean?

Bottlenecked is the demo starting state: the app ships with six realistic performance defects switched on so Azure Load Testing can surface them under load.

Optimized is the same code with those defects switched off, used for the after-the-fix comparison.

Switch modes at runtime with POST /admin/config and {"preset":"bottlenecked"} or {"preset":"optimized"}. No redeploy or restart is required.

The defects cover no caching on balance lookups, an undersized connection pool, a global lock on transfers, an N+1 transaction-history query pattern, sequential synchronous fraud and sanctions checks, and CPU-bound statement generation. The error-rate knob injects controlled 503 failures.
